## Global Constraints

### 已实测事实（2026-08-16，claude 2.1.233 / 本机）

1. **`--permission-prompt-tool <mcp_tool>` 存在可用**（rc=0 实测；`--help` 不列全 flag——勿以 help 缺失判断移除）。文档行为：Claude 等该 MCP server 连接（MCP_TIMEOUT 默认 30s）后跑首回合；v2.1.199+ 不能批准 `requiresUserInteraction` 的 MCP 工具；无审批通道时该次工具调用被 deny（不挂起，fail-safe）。
2. **`claude --bg "<prompt>"`**（prompt 走参数非 stdin）：stdout 首行 `backgrounded → <8hex id>` + 任务卡；**`claude agents --json [--all]`**：JSON 数组，字段 `pid/id/cwd/kind/startedAt(ms)/sessionId(UUID)/name/status/state`，state ∈ `working/completed/blocked`（活跃条目带 pid）；**`claude stop <id>`** → `stopped <id>`；`claude logs` 是 TUI 渲染流**不可解析**。宿主旧后台会话可能占位排队（简单任务曾 >90s 仍 working）——轮询超时要宽松（默认 30min）。completed 条目的结果字段**未取得样本**：实现时先实测；兜底 = `--resume <sessionId>` 单 turn 询问总结。
3. chrome-devtools server 命令（用户本机在用，直接复用）：`cmd /c npx chrome-devtools-mcp@latest`（Windows）；Linux 为 `npx chrome-devtools-mcp@latest`。context7：`npx @upstash/context7-mcp`。web-reader：`uvx mcp-server-fetch`（Anthropic 官方参考实现，抓取转 markdown；备选 jina reader，实测不通时换）。
4. MCP stdio transport = **newline-delimited JSON-RPC 2.0**（每行一个 JSON 消息）。握手：`initialize` 请求 → 响应 `{"protocolVersion":"2024-11-05","capabilities":{"tools":{}},"serverInfo":{"name":"daoyu-approval","version":"0.1.0"}}`；随后客户端发 `notifications/initialized`（通知，无 id，**不回包**）；`tools/list` → `{"tools":[{name,description,inputSchema}]}`；`tools/call` → `{"content":[{"type":"text","text":"..."}]}`。请求必须按 id 回响应；通知不回。
5. SQLite WAL 支持多进程并发读写（MCP server 子进程与主进程共享 `data/daoyu.db` 安全；WAL 下读不阻塞写）。连接方各自 `sqlite3.connect(path, timeout=30)`。
6. 其余 M1 硬约束全部继承（见 M1 计划 Global Constraints 1-22：iLink 协议、全量 flag、session 串行、stdin prompt、context_token、msg_id 去重、--bare、预算闸、deny `//` 锚定等）。

### 工程约束

7. mcp.json 进 git 但**不能含机器特定绝对路径**——审批 server 条目由 runner 在任务启动时生成**临时合并配置**（tempfile：静态 mcp.json + daoyu-approval 条目含绝对路径 env）传入 `--mcp-config`，任务结束删除。
8. 审批语义（TRD §4.4/§8）：strict 档 = `--permission-mode acceptEdits` + `--permission-prompt-tool mcp__daoyu__approve`；审批请求推微信 Y/N；**5 分钟（300s）无应答 = expired = 拒绝**；审批记录进 approvals 表 + audit。
9. `/bg` 是**桥命令**（本地拦截，不转发）：`/bg <prompt>` 创建 kind=bg 任务；runner 用 `claude --bg` 启动并立即回复任务已后台化；后台轮询协程经 `claude agents --json --all` 跟踪，完成后结果分页推送。`/cancel` 对 bg 任务走 `claude stop <bg_id>`。
10. 监控告警 = 关键事件写 outbox 推送白名单用户（复用出站通道）：死信产生、任务预算超限、日限熔断、token 失效重连。无新渠道（server酱/邮件归 M3 或后续）。
11. 每任务 TDD：测试 → RED → 实现 → GREEN → commit。子代理执行，跨任务接口签名不得偏离本计划 Interfaces 声明。

```python
CREATE TABLE IF NOT EXISTS approvals (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  task_id INTEGER NOT NULL,
  to_user TEXT NOT NULL,
  tool_name TEXT NOT NULL,
  input_json TEXT NOT NULL DEFAULT '',
```

```python
    # ---- approvals（审批，M2）----
    def create_approval(self, task_id: int, to_user: str, tool_name: str,
                        input_json: str) -> int:
        cur = self._conn.execute(
            "INSERT INTO approvals(task_id, to_user, tool_name, input_json, created_at) "
            "VALUES(?,?,?,?,?)",
            (task_id, to_user, tool_name, input_json, int(time.time())))
        self._conn.commit()
        return cur.lastrowid

    def decide_approval(self, approval_id: int, state: str) -> bool:
        cur = self._conn.execute(
            "UPDATE approvals SET state=?, decided_at=? "
            "WHERE id=? AND state='pending'",
            (state, int(time.time()), approval_id))
        self._conn.commit()
        return bool(cur.rowcount)

    def pending_approval(self, to_user: str):
        return self._conn.execute(
            "SELECT * FROM approvals WHERE to_user=? AND state='pending' "
            "ORDER BY id LIMIT 1", (to_user,)).fetchone()

    def get_approval(self, approval_id: int):
        return self._conn.execute(
            "SELECT * FROM approvals WHERE id=?", (approval_id,)).fetchone()
```

- [ ] **Step 2: MCP server 实现与子进程级测试**

```python
# worker/approval_mcp.py
"""刀鱼审批 MCP server（stdio）。claude 子进程经 --permission-prompt-tool 调用。

与主进程共享同一 SQLite（WAL 多进程安全）：approve 被调用 → 写 approvals 行 +
写 outbox 推微信 → 轮询用户 Y/N → 返回 approved/denied；300s 超时 = expired = 拒绝。
"""
import json
import os
import sqlite3
import sys
import time

POLL_S = 2
TIMEOUT_S = 300


def _conn():
    c = sqlite3.connect(os.environ["DAOYU_DB"], timeout=30)
    c.row_factory = sqlite3.Row
    return c


def _resp(id_, result):
    sys.stdout.write(json.dumps({"jsonrpc": "2.0", "id": id_, "result": result}) + "\n")
    sys.stdout.flush()


def _tools():
    return {"tools": [{
        "name": "approve",
        "description": "请求用户批准一次工具调用（微信 Y/N，5 分钟超时拒绝）",
        "inputSchema": {"type": "object",
                        "properties": {"tool_name": {"type": "string"},
                                       "input": {"type": "string"}},
                        "required": ["tool_name"]},
    }]}


def _approve(conn, args):
    task_id = int(os.environ.get("DAOYU_TASK_ID", "0"))
    to_user = os.environ.get("DAOYU_TO_USER", "")
    tool = args.get("tool_name", "?")
    inp = str(args.get("input", ""))[:300]
    cur = conn.execute(
        "INSERT INTO approvals(task_id, to_user, tool_name, input_json, created_at) "
        "VALUES(?,?,?,?,?)", (task_id, to_user, tool, inp, int(time.time())))
    conn.execute(
        "INSERT INTO outbox(task_id, to_user, text, created_at) VALUES(?,?,?,?)",
        (task_id, to_user,
         f"🔐 审批请求 #{cur.lastrowid}：允许执行 {tool}？\n{inp}\n回复 Y 允许 / N 拒绝",
         int(time.time())))
    conn.commit()
    aid = cur.lastrowid
    deadline = time.time() + TIMEOUT_S
    while time.time() < deadline:
        row = conn.execute("SELECT state FROM approvals WHERE id=?", (aid,)).fetchone()
        if row["state"] == "approved":
            return "approved"
        if row["state"] in ("denied", "expired"):
            return "denied"
        time.sleep(POLL_S)
    conn.execute("UPDATE approvals SET state='expired', decided_at=? "
                 "WHERE id=? AND state='pending'", (int(time.time()), aid))
    conn.commit()
    return "denied（超时 5 分钟未应答）"


def main():
    conn = _conn()
    for line in sys.stdin:
        line = line.strip()
        if not line:
            continue
        try:
            msg = json.loads(line)
        except ValueError:
            continue
        m = msg.get("method", "")
        if "id" not in msg:            # 通知（如 notifications/initialized）不回包
            continue
        if m == "initialize":
            _resp(msg["id"], {"protocolVersion": "2024-11-05",
                              "capabilities": {"tools": {}},
                              "serverInfo": {"name": "daoyu-approval",
                                             "version": "0.1.0"}})
        elif m == "tools/list":
            _resp(msg["id"], _tools())
        elif m == "tools/call":
            name = (msg.get("params") or {}).get("name")
            args = (msg.get("params") or {}).get("arguments") or {}
            if name != "approve":
                _resp(msg["id"], {"content": [{"type": "text",
                                               "text": "unknown tool"}],
                                  "isError": True})
                continue
            verdict = _approve(conn, args)
            _resp(msg["id"], {"content": [{"type": "text", "text": verdict}]})
        elif m == "ping":
            _resp(msg["id"], {})
        else:
            _resp(msg["id"], {})


if __name__ == "__main__":
    main()
```

注意：server 的 stdin/stdout 编码——Windows 管道默认 cp936，main() 开头 `sys.stdin.reconfigure(encoding="utf-8"); sys.stdout.reconfigure(encoding="utf-8")`（JSON-RPC 必须 UTF-8）。
